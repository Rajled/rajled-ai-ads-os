# SPR-001 — Core Framework

**Project:** RajLED AI Ads OS
**Sprint:** S1-001
**Target Version:** v0.1.0-alpha.1
**Status:** Ready for Implementation

---

# Sprint Goal

Build the foundational WordPress plugin framework for RajLED AI Ads OS.

This sprint must create the core structure required for all future engines and modules.

No Google Ads API integration is implemented in this sprint.

---

# Scope

## S1-001-01 Repository Bootstrap

Create base source structure:

```text
src/
├── Core/
├── Config/
├── Engine/
├── Health/
├── Logging/
├── Rest/
└── Dashboard/
```

---

## S1-001-02 WordPress Plugin Bootstrap

Create the main plugin entry point.

The plugin must activate without fatal errors.

---

## S1-001-03 Kernel

Create the main Kernel class responsible for initializing the system.

Responsibilities:

* load configuration,
* initialize services,
* register REST endpoints,
* register dashboard page,
* expose system version.

---

## S1-001-04 Engine Interface

Create a base EngineInterface.

Required methods:

```php
public function register(): void;
public function boot(): void;
```

---

## S1-001-05 Engine Registry

Create EngineRegistry.

Required methods:

```php
register(string $key, EngineInterface $engine): void;
get(string $key): ?EngineInterface;
all(): array;
count(): int;
```

---

## S1-001-06 Configuration Manager

Create ConfigurationManager.

Initial responsibilities:

* store plugin version,
* store REST namespace,
* expose basic configuration values.

---

## S1-001-07 Logger

Create a simple Logger service.

Initial methods:

```php
info(string $message, array $context = []): void;
warning(string $message, array $context = []): void;
error(string $message, array $context = []): void;
```

Logging may initially use WordPress debug log.

---

## S1-001-08 Health Manager

Create HealthManager.

It should return basic system status:

```json
{
  "status": "ok",
  "version": "0.1.0-alpha.1",
  "engines": 0
}
```

---

## S1-001-09 REST Bootstrap

Register REST endpoints:

```text
GET /wp-json/rajled-ai-ads/v1/health
GET /wp-json/rajled-ai-ads/v1/version
```

Responses must follow DOC-006 response format:

```json
{
  "success": true,
  "data": {},
  "meta": {},
  "errors": []
}
```

---

## S1-001-10 Dashboard Bootstrap

Create a WordPress admin menu page.

Page title:

```text
RajLED AI Ads OS
```

Initial dashboard should display:

* plugin name,
* version,
* system status,
* REST namespace.

---

# Out of Scope

Do not implement:

* Google Ads API,
* OAuth,
* GAQL,
* Snapshot Engine,
* Campaign Memory,
* Performance Engine,
* Opportunity logic,
* AI recommendations,
* execution workflow,
* automatic campaign changes.

---

# Acceptance Criteria

Sprint is accepted when:

* plugin activates without fatal errors,
* Kernel initializes successfully,
* EngineRegistry works,
* ConfigurationManager works,
* Logger exists,
* HealthManager returns status,
* REST `/health` endpoint works,
* REST `/version` endpoint works,
* WordPress dashboard page exists,
* implementation follows AGENTS.md,
* implementation follows ENGINEERING_STANDARDS.md,
* implementation follows CODING_STANDARDS.md.

---

# Definition of Done

S1-001 is complete when:

* code is implemented,
* no unrelated features are added,
* changed files are listed,
* testing steps are documented,
* documentation remains consistent,
* implementation is ready for review.
