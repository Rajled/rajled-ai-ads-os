# Sprint S1-005 — Integration to Domain Bridge

**Status:** Accepted

**Release:** v0.2.0-alpha.4

---

## Sprint Goal

Establish the first verified bridge between the Google Ads Integration Layer and the provider-independent Domain Layer.

The sprint introduces concrete Google Ads mappers that transform normalized provider-neutral data into Domain objects while preserving complete isolation from the official Google Ads SDK.

---

## Completed Tasks

### TASK-005.1 — Architecture Discovery

Reviewed the existing Google Ads Integration and SDK boundaries.

Confirmed:

- native Google Ads SDK objects do not currently leak outside the SDK namespace;
- existing mapping contracts are sufficient;
- provider-neutral DTOs are not required at this stage;
- concrete Google Ads mapper implementations belong under `src/Integration/GoogleAds/Mapping/`.

**Status:** Accepted

---

### TASK-005.2 — Google Ads Domain Mappers

Implemented:

- `GoogleAdsCampaignMapper`
- `GoogleAdsMetricsMapper`
- `InvalidGoogleAdsMappingDataException`

The mappers:

- accept provider-neutral arrays;
- validate required keys and structural input types;
- create existing Domain objects;
- allow Domain validation exceptions to propagate;
- introduce no Google Ads SDK dependencies;
- do not modify the Domain Layer.

**Status:** Accepted

---

## Deferred Task

### TASK-005.3 — Google Ads Campaign Reader

An initial reader implementation was reviewed and rejected because it relied on speculative assumptions about the official Google Ads SDK.

The implementation was removed.

The task is deferred to S1-006 because the repository currently lacks:

- the official Google Ads PHP SDK dependency;
- an initialized native SDK client;
- a verified campaign query implementation;
- confirmed SDK response types and enum behaviour.

**Status:** Deferred
