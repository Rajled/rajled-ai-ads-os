# Changelog

All notable changes to **RajLED AI Ads OS** are documented in this file.

The project follows:

* Semantic Versioning (SemVer)
* Incremental Releases
* Sprint-based Development
* Architecture Decision Records (ADR)

Each release represents a stable and reviewable milestone.

---

# Changelog Format

Each release is organized into the following sections whenever applicable:

* Added
* Changed
* Deprecated
* Removed
* Fixed
* Security
* Documentation
* Architecture

Not every release will contain every section.

# Release Policy

Each version must satisfy the following requirements before release:

* Architecture review completed
* Documentation synchronized
* Sprint completed
* Regression verification completed
* Release Notes prepared

Only stable releases are recorded in this changelog.
